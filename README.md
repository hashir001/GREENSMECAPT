# GreenSMECapt

GreenSMECapt is an AI-driven platform for assessing sustainable SMEs and financing opportunities.

The platform converts business documents into source-linked evidence, combines environmental and financial assessment, and supports transparent comparison for investors.

## Core Features

- Document processing and AI-assisted evidence extraction
- Traceable environmental and financial assessment
- Evidence review and SME verification
- Investor comparison and decision support
- Role-based workspaces for SMEs, reviewers, experts, investors and administrators

## Technology

React, TypeScript, Python, FastAPI, PostgreSQL, Supabase, Google Document AI and Gemini through Vertex AI.
